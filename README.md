# TFG - Andrea Medrano Romera

Material asociado al Trabajo de Fin de Grado: **Análisis de tráfico de aplicaciones móviles: evaluación de herramientas y caracterización de tráfico**

## Contenido

- `DQFApp.zip`: proyecto completo de la aplicación Android DQF.
- `CodigoFuenteDQF.zip`: principales archivos de código fuente de DQF.
- `CodigoAnalisis.ipynb`: cuaderno de Python utilizado para analizar las capturas.
- `RegistrosCSV.zip`: registros generados por DQF durante la campaña.
- `ResultadosAnalisis.zip`: tablas y gráficas obtenidas mediante el análisis.
- `CapturasPCAP.zip`: capturas de tráfico de la campaña experimental.
- `APKs.zip`: APK de la aplicación DQF y documento con los enlaces de descarga de las aplicaciones utilizadas durante las pruebas.

Los archivos `CapturasPCAP.zip` y `APKs.zip` se encuentran disponibles en la sección **Releases** del repositorio.
